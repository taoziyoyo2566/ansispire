# Scenario: New Feature

1. Confirm the feature fits the current architecture rather than layering onto an anti-pattern.
2. If the task is architectural, ensure there is an approved or at least active plan doc in `docs/reviews/`.
3. Define boundaries clearly: touched files, untouched files, and follow-up items.
4. Prefer existing SSOTs over new parallel mechanisms.
5. Decide required sync targets and tests before finishing.
