# Scenario: New Feature

1. Read `.agents/rules/coding-plan.md` before editing code or executable configuration.
2. Confirm the feature fits the current architecture rather than layering onto an anti-pattern.
3. If the task is architectural, ensure there is an approved or at least active
   direction plan in the topic evidence directory resolved by
   `.agents/rules/file-naming.md`.
4. Define boundaries clearly: touched files, untouched files, and follow-up items.
5. Prefer existing SSOTs over new parallel mechanisms.
6. Decide required sync targets and tests before finishing.
