## Behavior

- Worker reads the configured Semaphore `static` inventory and lists hosts from `[vps_targets]`.
- `POST /vps` can create a Semaphore key, upsert the host in the inventory blob, and trigger the onboard template when `SEMAPHORE_ONBOARD_TEMPLATE_ID` is configured.
- Task trigger payload uses the confirmed Round 7 contract: `environment: JSON.stringify({ vps_task })`.
- `PUT /vps/:alias` updates an existing host in the blob.
- `DELETE /vps/:alias` removes an existing host from the blob.
- `POST /vps/:alias/audit` triggers the audit template when configured.
