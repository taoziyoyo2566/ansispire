## Intent per change

- **The 3 renames**: address Codex F1 at the root. Ansible auto-loads any `.yml` / `.yaml` / `.json` file in `inventory/<env>/group_vars/<g>/` or `host_vars/<h>/`. Moving examples to `inventory/examples/` (NOT under any env inventory) removes the auto-load risk entirely; today's fragile alphabetical-sort protection is no longer needed.
- **Self-reference edits**: ensure the workflow instructions inside the moved files reflect the new copy-out source path.
- **README**: makes the "inert documentation tree" intent obvious so future contributors don't recreate the problem.
