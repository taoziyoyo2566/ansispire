## §2. Work Units

### WU-1 — Makefile audit URL dynamic from .env
**File**: `Makefile:295-299` (target `controller-audit-up`).
**Change**: replace hardcoded `:3310` in the echo with a runtime read of `AUDIT_PORT` from `$(CONTROLLER_ENV)`, defaulting to 3310 when the env file does not define the key.
**Why**: source of the Codex Round-3 drift (Makefile said 3010, compose said 3310). Reading from `.env` makes Makefile output track manifest-sync output, eliminating the class of bug entirely.

### WU-2 — `scripts/archive_branch.sh`
**New file**.
**Signature**: `./scripts/archive_branch.sh <BRANCH> <MERGE_TARGET> <PR_NUMBER>`
**Behavior**:
1. Validate args.
2. Reject if BRANCH is `dev` / `master` / `main`.
3. Reject if working tree dirty or HEAD == BRANCH (must run from elsewhere).
4. Verify BRANCH is merged into MERGE_TARGET via `git merge-base --is-ancestor`.
5. Tag `archive/<BRANCH-flat>-<YYYY-MM-DD>` with annotation referencing PR + target.
6. Refuse to overwrite an existing archive tag (no-clobber).
7. Push tag, then push :BRANCH, then delete local BRANCH.
8. Print final summary.
**Why**: closes Codex finding "归档命令对 fix/ 分支不安全" by replacing the hand-edited recipe with a parameterized script. Reduces the chance of `git push origin :feat/<parent>` typo when archiving a `fix/`.

### WU-3 — CLAUDE.md wikilink linter
**New file**: `scripts/check_claude_md_links.sh`.
**Behavior**: grep `[[...]]` in all `CLAUDE.md` files in repo (`CLAUDE.md`, `~/workspace/CLAUDE.md` is out of scope as it's not in this repo). Exit non-zero with file:line on any hit. Rationale: wikilinks are a personal-memory namespace convention; they should never appear in repo-tracked governance files.
**Makefile**: add `check-claude-links` target + chain into `verify`.
**Why**: closes Codex finding "[[feedback-branching-model]] 死引用" by making the same mistake fail CI / pre-commit.

### WU-4 — `make review-local`
**Makefile**: new target `review-local` (no script needed, all inline shell).
**Behavior**: compute `BASE = git merge-base @{u} HEAD`, then print:
1. base SHA + short message
2. `git diff --stat $BASE..HEAD`
3. `git diff --name-status $BASE..HEAD`
4. `git diff --check $BASE..HEAD` (whitespace/conflict markers)
**Why**: closes Codex suggestion #3 of "流程优化". Speeds up the "what am I about to push" sanity check before `push-and-watch-pr.sh`.

### WU-5 — Land stashed dev-tooling scripts
**Files**: `scripts/push-and-watch-pr.sh` + `scripts/watch-pr-checks.sh` (already popped from `stash@{0}`).
**Why**: these scripts encode the `push to PR branch → background watch CI` workflow that this very session has been using. Bundling them with the other dev-tooling work is the natural home — same topic, same audience, same review pass.
