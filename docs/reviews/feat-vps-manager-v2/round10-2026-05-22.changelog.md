## 2. Why fail-loud, not skip-and-warn

Two design choices were on the table:

| Approach | Trade-off |
|---|---|
| Skip + warn (filter out bad aliases, log to stderr, return only the valid rows) | Soft failure; operator might not notice the corruption; `vps-runner list` keeps working partially. |
| Fail-loud raise (chosen) | First malformed alias terminates the listing. Operator sees the corruption immediately, fixes hosts.yml, retries. Matches the existing `read_host_vars` / `add_host` / `delete_host_vars` semantics — they all already raise on path-validator misses. |

Consistency with the rest of the chokepoint won: `list_hosts` now behaves like every other host_vars path-consumer in the module. Inventory corruption is exceptional state that should not be silently masked.

The reviewer explicitly suggested this approach (「fail-loud 抛 VpsRunnerError，让 inventory corruption 明确暴露」). No public-API surface change for legitimate inventory — only malformed inputs hit the new error path.

## 3. Defense-in-depth status (post-R10)

Every alias path-consumer in `plugins/vps_runner/vps_runner.py` now routes through one of two chokepoints:

```
inventory side                            ssh-config side
─────────────                             ───────────────
host_vars_path(env, alias)                write_ssh_config(...) / delete_ssh_config(...)
  ↓ used by:                                ↓ direct validation:
  - read_host_vars   ✓                       _validate_alias    ✓
  - write_host_vars  ✓                       _validate_hostname ✓
  - delete_host_vars ✓                       _validate_ssh_user ✓
  - add_host         ✓ (also direct validate)  _assert_path_in_dir ✓
  - list_hosts       ✓ (R10 — was the gap)
```

`list_aliases()` itself remains intentionally non-validating: it returns whatever keys live in hosts.yml. The validation is enforced at the next layer (any code that turns an alias into a filesystem path). This separates "what's in the inventory" from "what's a valid alias" — a corruption detector, not a corruption hider.
