## 2. Behavior Changes

- `onboard --first-time` no longer injects `ansible_user`, `ansible_port`, or `ansible_ssh_private_key_file` as extra-vars. Those names are reserved for Ansible connection behavior and extra-vars cannot be overridden later in the play.
- First-time runs now pass `vps_first_time`, `vps_first_time_user`, `vps_first_time_port`, and optional `vps_first_time_key`.
- `onboard.yml` selects the bootstrap channel before gathering facts, then switches to the managed channel with host facts before final SSH lockdown.
- If `--first-time` is used on a host whose managed channel already works, the CLI runs normal managed repair mode.
- Existing-alias wizard verification now chains basic verify -> audit policy findings -> optional managed repair, so operators decide based on concrete drift/non-running items.
- fail2ban enable paths now restart the service after jail changes and prove both service active state and `sshd` jail load.
